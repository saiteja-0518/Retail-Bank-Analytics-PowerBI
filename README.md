# Retail Bank Analytics | Power BI Project

##  Project Overview

Retail Bank Analytics is an interactive **Microsoft Power BI dashboard** developed to analyze banking data and understand customer behaviour, account activity, transaction patterns, loan performance, and card usage.

The project transforms raw banking data into meaningful visualizations and business insights that can help understand overall banking performance.

---

##  Project Objectives

The main objectives of this project are:

- Analyze customer profiles and segmentation
- Understand account types and account activity
- Analyze transaction trends and transaction channels
- Study loan distribution and repayment behaviour
- Analyze card usage and product engagement
- Create an executive-level summary of the key findings

---

##  Dashboard Pages

The project contains **7 interactive dashboard pages**:

### 1. Overview
Provides a high-level view of the overall banking data, including customers, accounts, loans, transactions, cards, account types, transaction channels, loan types, and branch performance.

### 2. Customer Analytics
Analyzes:
- Customer segments
- Gender
- State-wise customers
- Average income
- Credit score
- KYC status
- Customer signup trends

### 3. Account Analytics
Analyzes:
- Account types
- Active and closed accounts
- Account balances
- Branch-wise account activity
- Average account balance
- Interest rates

### 4. Transactions Analytics
Analyzes:
- Transaction value trends
- Transaction count
- Transaction channels
- Transaction descriptions
- Customer segments
- Transaction performance

### 5. Loans Analytics
Analyzes:
- Loan types
- Loan status
- EMI amounts
- Loan payments
- Principal and interest paid
- Payment methods
- Late payments
- Penalties

### 6. Cards Analytics
Analyzes:
- Card types
- Active and inactive cards
- Credit limits
- Outstanding balances
- Card networks
- Card engagement

### 7. Executive Banking Summary
Provides the major findings and business insights from the complete analysis.

##  Key Insights

- **75% of customers are active**, with 375 active customers out of 500.
- **71% of accounts are active**, with 497 active accounts out of 700.
- Around **5K transactions** were analyzed with a total transaction value of **₹35.89M**.
- **Online** recorded the highest transaction value among the transaction channels.
- **Education loans** had the highest count among the loan types.
- The loan analysis recorded **₹18.77M in principal paid** and **₹2.40M in interest paid**.
- Only **37 out of 600 cards are active**, highlighting an opportunity to improve card engagement.
